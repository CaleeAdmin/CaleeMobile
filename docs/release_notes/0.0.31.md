# 0.0.31

## What's New

- Guest mode now supports up to five followed local calendars. Reaching the
  limit shows a clear explanation with the option to create a Calee account
  for your home instead of a generic error, and calendars you already follow
  always reopen without being counted twice.
- Compatibility update for the latest Android release (Android 16), keeping
  Calee aligned with Google Play's current platform requirements.
- Maintenance improvements to the onboarding flow after registration.

## Internal notes

- Local-calendar allowance is enforced in the domain layer
  (`LocalCalendarSubscriptionRepository.add()` throws a typed
  `LocalCalendarSubscriptionLimitException` for a genuinely new sixth
  calendar; duplicates are returned successfully and storage is never
  mutated at the limit), so every calendar-follow ingress path inherits the
  same behaviour (#536/#537).
- `targetSdk` raised to 36 (Android 16) to meet Google Play's 31 August 2026
  requirement; every behaviour change activating at targetSdk 36 was audited
  with no code changes required, and
  `test/platform/android_target_sdk_test.dart` pins the build-configuration
  outcomes (#538).
- The post-registration onboarding steps carry stable widget keys for the
  regression suite's selector contract (#542).
- App Store / Google Play release operations were formalised
  (release preflight, manifest and ref verification tooling) (#539, #541).
