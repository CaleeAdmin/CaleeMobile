# 0.0.31

## What's New

- Following shared calendars is easier, with clearer guidance after installing
  Calee from a shared calendar link.
- Guest mode now supports up to five local calendar subscriptions and provides
  a clearer way to manage existing calendars when the limit is reached.
- Improved compatibility with newer Android versions.

## Internal notes

- Android now targets and compiles against API 36, with regression coverage for
  the Android 16 configuration requirements used by Calee.
- Includes the stable post-registration onboarding selectors required by the
  CaleeMobile-Regression SUCCESS-1 flow. These selectors do not change product
  behaviour.
- Adds repository-controlled release preflight, signing, release-evidence and
  artifact-traceability tooling. The workflows build and validate release
  artifacts but do not automatically publish them to either store.

## Device qualification

- Android: the 0.0.31 VM/emulator rehearsal passed on Android 17 / API 37;
  physical-device release qualification is still required.
- iOS: to be recorded by the Release Operator at release time.
